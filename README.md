## 👩‍💻 About Me

I'm a Software Engineer currently pursuing an M.Sc. in Web Engineering at TU Chemnitz, Germany, where I also work as a Student Research Assistant contributing to research-oriented web applications and AI-assisted software.

My main focus is frontend development, building clean, modern, and user-centered applications with React and TypeScript while continuously improving through hands-on projects and real-world experience.

Alongside frontend engineering, I'm interested in usability, AI integration, and research-driven software development that combines technical implementation with thoughtful user experience.

Currently, I'm researching AI-augmented FAIRness assessment for research software repositories as part of my master's thesis, combining LLM-based analysis with rule-based evaluation approaches.
